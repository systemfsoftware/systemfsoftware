Add the `./report` entry. `buildReport` turns a worker's attempt log into a `report-1` document: one result per test, target and agent with every attempt in order, the run status and exit code folded from each final attempt, and a summary counted from the results. `mergeReports` merges the partial reports of one run into one report that is the same in any order, and refuses partials of different runs or with a result in common. `decodeReport` and `report1JsonSchema` read and describe the document. The `list`, `json`, `junit` and `markdown` reporters render it with matching counts; `emitReports` writes `junit.xml` and `summary.md` under the output directory and returns the terminal text for `list` and `json`. `TestSession.layer` now also needs an `ArtifactStore` (`FileArtifactStore` or `MemoryArtifactStore` from `./run`): a try the `trace` setting admits (by default, any non-passing try) leaves `trace.md`, a masked `screen.png` and a redacted `screen.txt` under `<output>/results/<title slug>-<8 hex digits>/`, read within 5 seconds before the engine closes and listed in the result's `artifacts` and `tracePath`; a refused evidence write is recorded on the attempt as `ARTIFACT_WRITE_FAILED`. Assert and wait-for steps now carry their cache lookup and write, model calls and tokens, and extract steps carry model calls, tokens and the lookup `Off`. `exitCodeOf` maps a `RunEnding`, a judged verdict or a refused config (exit 2), to its exit code. `Attempt` moved from `.` to `./report`. These breaking changes ship as a minor bump because the package is pre-1.0 and has not been published to npm.
