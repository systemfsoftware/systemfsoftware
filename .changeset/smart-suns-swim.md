Add `assert`, `waitFor` and `extract` to the `./agent` entry. `assert` and `waitFor` have the model resolve a sentence into a closed check once, with one repair, and decide it with a pure three-valued evaluation: holds passes, does not hold fails `ASSERTION_FAILED`, and a fresh check the screen cannot support ends `ASSERTION_INCONCLUSIVE`. No model answer is a verdict. A check that held is staged for the cache and replays with zero model calls; a stale recorded check is re-resolved with one call. `waitFor` polls every `interval` (3 s) until `timeout` (30 s), and on timeout its last evaluation decides the code. `extract` takes a schema that is both Standard Schema and Standard JSON Schema, validates the model's value with one repair, and fails `MODEL_OUTPUT_INVALID` on a second invalid answer. `vision: true` adds a masked screenshot and `'only'` sends the screenshot without the tree; a model or engine that cannot serve the mode fails `UNSUPPORTED_CAPABILITY` before any model call. A failed assertion records a model-proposed cause with cited evidence, which never changes its code, cause or the run status. Model specs gain `vision` (default `false`). Cache keys gain `step: 'act' | 'judgment'`, so every recorded cache entry from an earlier version misses once and is re-recorded, and a passing assertion confirms its own recording.
