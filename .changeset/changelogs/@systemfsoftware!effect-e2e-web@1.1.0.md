# @systemfsoftware/effect-e2e-web@1.1.0

New package. `@systemfsoftware/effect-e2e-web` provides the web engine for `@systemfsoftware/effect-e2e`: `layer({ spec, contextHeaders })` builds the `Engine` service over a Playwright browser from a `web(...)` spec, launching the browser once per layer and opening a fresh browser context for every `open`. It reads the page as a semantic tree from Playwright aria snapshots, finds elements by role, label, placeholder, text, test id, CSS selector, filter, index and frame, performs taps, fills, typing, key presses, selection, checking, hovering, drags, swipes and point actions, reads text, values, attributes, visibility, enabled and checked state and bounds, takes masked PNG screenshots, and records console messages, page errors, failed requests and 4xx/5xx responses. Failures are the engine codes: several matches `LOCATOR_AMBIGUOUS`, no match `LOCATOR_NOT_FOUND`, a matched element that cannot be used `ACTION_FAILED`, a page that cannot load `APP_UNREACHABLE`, a secret or credential fill `AUTOMATION_UNSUPPORTED`, and a browser that cannot launch `ENVIRONMENT_UNAVAILABLE`. Each `contextHeaders` value is sent as an HTTP header on every request of the context, to every origin; the engine never writes it into its own output, but a page that renders or logs the header shows it in `observe` and `logs`. Declared capabilities: `web`, `screenshot`, `vision`, `network`, `drag`, `frames`. `playwright` is a peer dependency; install the browser with `playwright install chromium`.
