# @systemfsoftware/vitest@4.0.0

Rebuilt against the new `@systemfsoftware/oxlint-config-recommended` and `@systemfsoftware/oxlint-plugin-test-discipline` releases; the exported API is unchanged. No change a consumer can observe. `DuplicateCapture` and `OutlineDuplicateRowName` (storybook-gherkin) and `SelfModelLaw` (vitest) no longer carry a payload field called `name`, which shadowed the error's own `name`. Read `capture` on `DuplicateCapture`, `row` on `OutlineDuplicateRowName` and `law` on `SelfModelLaw`. Their classes also carry a nominal brand in their type, so an object literal with the same fields no longer satisfies the instance type. turbo moved 2.11.8 -> 2.11.10 The property runner loads the Node file system and path layers when a property first runs, so importing the runner in a browser test no longer evaluates Node-only modules (effect 4.1.0's Node file system reads `process` on import).
