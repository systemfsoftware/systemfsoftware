Adds the package: `catalog.laws` tests a module's private decision core in place with library-owned reserved-input generators and an authored published-contract shape, so refusal properties and named contract values are declared rather than scripted, and registrations run only inside a test runner. Refuse homes beyond the built-in ceremony families are licensed through `refuseHomes.region`, which takes an arbitrary over the domain's refusing inputs and applies the same detection law to every draw.

Removes the unconsumed refuse-home families (`invalidSocketPath`, `sshParentConflict`, `quadletDir`); only `reservedEnvFile` and `region` remain (alpha breaking change, allowed pre-1.0). `region` now rejects a degenerate arbitrary at registration: 8 samples producing fewer than 2 distinct values throws. The `inverse` law now requires `published` at the type level — passing an inverse without a published contract is a type error, with the runtime throw kept as defense. Exports the `LiteralBounded` and `PublishedCaseRuntime` types.
