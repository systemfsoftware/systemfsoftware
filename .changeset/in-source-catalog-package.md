Adds the package: `catalog.laws` tests a module's private decision core in place with library-owned reserved-input generators and an authored published-contract shape, so refusal properties and named contract values are declared rather than scripted, and registrations run only inside a test runner. Refuse homes beyond the built-in ceremony families are licensed through `refuseHomes.region`, which takes an arbitrary over the domain's refusing inputs and applies the same detection law to every draw.
