Add the `./run` entry: the per-try run engine. `TestSession.layer(input)` builds one try of one test from its config, target, agent, a fresh secret ledger and an engine source, and needs only `ModelGateway` and `CacheStore`. Its `open`, `act`, `assert`, `waitFor` and `extract` each start a step and return a handle whose `join` awaits it. The engine opens on first use, at most once per try, so a test that never touches the app or the screen opens no browser. `endAttempt(ending)` is uninterruptible: it interrupts steps still running, closes the engine if it was opened, settles and writes the replay cache, and appends the attempt to an `AttemptLog`. A step that was never joined, or was still running when the test returned, fails the try `STEP_NOT_AWAITED`. A cache write that fails marks that step `not-written` and never changes the status. `admitTest` skips a test whose `platforms` do not include the target's platform, recording a skipped attempt with the reason, and the log's `verdict` decides the run from each test's final attempt, so a test that passes on retry passes the run. In `report-1`, an attempt is now `Ran { id, retry, status, steps, errors }` or `Skipped { id, retry, reason }`; no report-1 producer has shipped, so no stored report changes. The root entry exports the `Attempt`, `RunVerdict` and `TestPlatform` types.
