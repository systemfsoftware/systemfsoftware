# gritlint

`gritlint` runs GritQL rule packs over the config files of a repository. It embeds the MIT-licensed GritQL engine
from `biomejs/gritql` at one pinned commit. Code lives in `apps/gritlint` (CLI, exit contract), `crates/gritlint_core`
(engine adapter, rules, scan, report, fixtures) and `packs/` (bundled rules beside their fixtures, embedded at build
time); `npm/gritlint` is the launcher, `nix/gritlint*.nix` the flake package and sandbox. Each rule below names the gate
that catches a violation.

## Engine

| Rule                                                                                                                                                                                                  | Gate                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| The pinned engine is reached through `gritlint_core::engine` only: never `marzano-gritmodule`'s resolver, `find_user_grit_dir` or the standard-library fetch, and never a read of `$HOME` or the cwd. | `cargo test --workspace`: `engine_contract.rs::a_poisoned_home_and_cwd_change_nothing` |
| No network-bearing engine feature: `embeddings`, `ai_builtins`, `grit_tracing`, `external_functions`, `network_requests`.                                                                             | `pnpm gate:rust`: the `cargo tree -e features` check                                   |
| Every engine behaviour gritlint relies on has a scenario in `crates/gritlint_core/tests/engine_contract.rs`; a re-pin runs them before it lands.                                                      | `cargo test --workspace`                                                               |
| The engine pin is one `rev` in `crates/gritlint_core/Cargo.toml` plus `Cargo.lock`; `nix/gritlint.nix` reads it from the lock.                                                                        | `cargo deny check`: `[sources] allow-git` names `biomejs/gritql` only                  |

## Core

| Rule                                                                                                                                                                                           | Gate                                                                                                                                                                             | Derives from                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every command is `read → decode → decide → encode → write`; only `shell` touches `std::fs`, `ignore::` or `std::env`, and `main.rs` wires the port.                                            | `cargo clippy -D warnings` — `clippy::disallowed_methods`, `clippy::disallowed_types`, allowed only in `shell.rs`                                                                | `compound-packs/cell-architecture/sandwich-phase-order.md`                                                                                                                        |
| A decide module has no `for`, `while` or `loop`; branching is an exhaustive `match` over a closed enum, iteration is combinators.                                                              | `pnpm gate:rust` grep over `crates/gritlint_core/src/decide.rs`; `clippy::cognitive_complexity`, `clippy::wildcard_enum_match_arm`, `clippy::match_wildcard_for_single_variants` | `compound-packs/cell-architecture/pure-decision-workflows.md`                                                                                                                     |
| Decode never casts: external shapes become newtypes with private fields (`RuleId`, `PackName`, `ParamName`, `RelPath`, `Language`) and `NonEmpty`; refusals are typed, never strings.          | `cargo clippy -D warnings` — `clippy::unwrap_used`, `expect_used`, `panic`, `unreachable`, `indexing_slicing`, `as_conversions`, `string_slice`; `tests/relpath_refusals.rs`     | `compound-packs/cell-architecture/decode-never-cast.md`, `compound-packs/cell-architecture/four-channel-contracts.md`                                                             |
| A rule is `ParsedRule → CompiledRule`; only a `CompiledRule` (sealed in `decode::compile_rule`) is evaluated. `SelectedFiles` is non-empty and `ScanPlan` builds the multifile partition once. | `cargo test --workspace` — `tests/laws.rs`                                                                                                                                       | `compound-packs/cell-architecture/staged-lawful-builders.md`, `compound-packs/boundary-testing/staged-protocol-evidence.md`                                                       |
| Laws, not examples: proptest laws for partition, order-independent encoding, the exit decision and `RelPath` decode; values are generated constructively, never by rejection sampling.         | `cargo test --workspace` — `tests/laws.rs`, `tests/relpath_refusals.rs`                                                                                                          | `compound-packs/schema-laws/fake-and-real-store-laws.md`, `compound-packs/schema-laws/arbitrary-filter-floors.md`, `compound-packs/schema-laws/refusals-beside-generated-laws.md` |
| The shell is tested against real tempdirs; the engine stays pinned by `tests/engine_contract.rs`.                                                                                              | `cargo test --workspace`                                                                                                                                                         | `compound-packs/boundary-testing/real-system-oracles.md`, `compound-packs/boundary-testing/pin-dependency-semantics.md`                                                           |

## Review-gated rules

| Rule                                                                                          | Wrong                                                | Right                                                 | Derives from                                                                                                                    |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Domain and evidence types keep private fields; construction is decode or a smart constructor. | a `pub` field on `Outcome` read directly by `decide` | `RuleId`/`RelPath` private fields with read accessors | `compound-packs/cell-architecture/handle-state-privacy.md`, `compound-packs/cell-architecture/resource-vs-handle-duality.md`    |
| `lib.rs` re-exports one public surface; the core never constructs I/O.                        | `decode` calling `std::fs::read_to_string`           | `decode` takes `&RawTree`; `shell` reads              | `compound-packs/cell-architecture/single-namespace-barrel.md`, `compound-packs/cell-architecture/ports-separate-from-layers.md` |
| Tests assert consumer-visible behaviour only.                                                 | a test asserting a config struct's field shape       | a test asserting a finding's path, line and message   | `compound-packs/boundary-testing/no-mocks-on-internal-glue.md`                                                                  |

Run the whole gate with `pnpm gate:rust` (`scripts/tools/gate-rust.sh`): fmt, clippy `-D warnings`, the decide-loop
grep, workspace tests, `test packs`, the config schema drift check, the engine network-feature check and
`cargo deny check`.
