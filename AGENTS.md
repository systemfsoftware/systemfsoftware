# constitution

The organization's shared `CODING_STANDARDS.md` and `REVIEW.md`. Consumer
repositories vendor this repository at `repos/constitution/`. There is no code
here.

- Read `CODING_STANDARDS.md`, `REVIEW.md` and `CONTRIBUTING.md` before you
  change a rule.
- This repository is public. Nothing private goes in it (`SF-SEC-1`).
- Verify with `deno task check` before you push. Never pass `--no-verify`.
- Work on a branch; `main` changes only through a pull request.
