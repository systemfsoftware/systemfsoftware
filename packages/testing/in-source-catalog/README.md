# @systemfsoftware/in-source-catalog

In-source test laws with library-owned generators. In an adopting package,
`catalog.laws` is the only in-source authoring surface: `reserved` refuse homes
come from library-minted generators, `published` values come from the named
contract table, and ceremony shapes (self-asserted markers, SUT-reconstructed
expectations, silent early returns, vacuous predicates) have no representable
form.

Laws are licensed only where a refusal boundary or a named published contract
exists; the adopting-package census sorts blocks into adopt and evict. Collection
is the canonical `import.meta.vitest` guard token wrapped around the laws call.

Status: pre-1.0 ALPHA. The laws core lands with the package's first feature
change; this scaffold ships the build and publish shape.
