# @systemfsoftware/stryker-js-util

A source-code fork of the upstream StrykerJS util package, pinned at 9.6.1

## Install

```sh
pnpm add @systemfsoftware/stryker-js-util
```

## Entry points

- `@systemfsoftware/stryker-js-util`

## Use

Utilities are re-exported from the single entry point:

```ts
import { deepMerge, StrykerError, Task } from '@systemfsoftware/stryker-js-util'
```

## API

The public surface is generated from the source and versioned with the package: [`etc/stryker-js-util.api.md`](./etc/stryker-js-util.api.md).
