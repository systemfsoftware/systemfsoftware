# @systemfsoftware/stryker-js-plugin-api

The plugin API of the @systemfsoftware Stryker fork

## Install

```sh
pnpm add @systemfsoftware/stryker-js-plugin-api
```

## Entry points

- `@systemfsoftware/stryker-js-plugin-api/check`
- `@systemfsoftware/stryker-js-plugin-api/core`
- `@systemfsoftware/stryker-js-plugin-api/ignore`
- `@systemfsoftware/stryker-js-plugin-api/logging`
- `@systemfsoftware/stryker-js-plugin-api/plugin`
- `@systemfsoftware/stryker-js-plugin-api/report`
- `@systemfsoftware/stryker-js-plugin-api/test-runner`

## API

The public surface is generated from the source and versioned with the package: [`etc/stryker-js-plugin-api.api.md`](./etc/stryker-js-plugin-api.api.md).
