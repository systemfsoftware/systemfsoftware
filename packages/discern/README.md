# @systemfsoftware/discern

Uncertainty-aware semantic pattern matching and control flow for Effect — forked under systemfsoftware from doeixd/discern.

## Install

```sh
pnpm add @systemfsoftware/discern 'effect@4.0.0-rc.116'
```

`effect` is a peer dependency: this package declares it but does not install it, so one copy is shared with the rest of your project.

## Entry points

- `@systemfsoftware/discern`
- `@systemfsoftware/discern/procedure`

## API

The public surface is generated from the source and versioned with the package: [`etc/discern.api.md`](./etc/discern.api.md) and [`etc/procedure.api.md`](./etc/procedure.api.md).
