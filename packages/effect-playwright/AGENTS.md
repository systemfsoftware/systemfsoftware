# AGENTS.md — `@systemfsoftware/effect-playwright`

Root `AGENTS.md` governs; these are the facts no default gate reports. Design and rejected alternatives: `docs/plans/2026-09-25-2045-feat-effect-playwright-lift-plan.md`. The `./test` entry derives from [`Jobflow-io/effect-playwright`](https://github.com/Jobflow-io/effect-playwright) 0.8.0-2; its MIT notice is in `NOTICE`.

| ID      | Rule                                                                                                                                                                                                                                                    | Gate                                                                                                    |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **PW1** | No export forwards a single Playwright call. Callers use Playwright's objects through `attempt`/`acquire`; an export exists only for behaviour Playwright lacks (typed errors, scope-bound lifetime, ending streams, Effect callbacks, the test entry). | `review`                                                                                                |
| **PW2** | No `src/` module imports a Node builtin (`node:*` or bare `fs`/`stream`/...); the only process boundary is Playwright itself.                                                                                                                           | `git grep -n -E "from '(node:\|fs\|stream\|path\|os)" -- packages/effect-playwright/src` prints nothing |
| **PW3** | No exported declaration carries `@internal` and no module sits under an `internal/` segment.                                                                                                                                                            | `git grep -n -E '@internal\|/internal/' -- packages/effect-playwright/src` prints nothing               |
| **PW4** | The `./test` entry's e2e lane holds at most four journeys, under `e2e/*.pw.ts`; anything else belongs in a vitest integration feature.                                                                                                                  | `git grep -c 'test.effect(' -- packages/effect-playwright/e2e` prints at most `4`                       |
