# @systemfsoftware/rightsize

Testcontainers-style container testing in Effect-TS: a complete, owned rebuild
of [rightsize-node](https://github.com/ngriaznov/rightsize-node) (behavioral
source, Apache-2.0; see `NOTICE`), with two execution backends — Docker Engine
over a unix-socket-only client, and microsandbox microVMs via the `msb` CLI —
an agent-native exec/inspection surface, and a public API at or beyond
testcontainers' surface. The design record is the port plan
(`docs/plans/2026-08-16-001-feat-rightsize-effect-port-plan.md`); the
ownership decision record is
`docs/solutions/tooling-decisions/rightsize-own-effect-port.md`.

## Quickstart

```ts
import { fromImage, layerAuto, layerRuntimeDiscovery, RightsizeConfig } from '@systemfsoftware/rightsize'
import { layerDocker } from '@systemfsoftware/rightsize/backend-docker'
import { Effect, Layer } from 'effect'

const program = Effect.gen(function*() {
  const container = yield* fromImage('redis:8.6-alpine')
    .withExposedPorts(6379)
    .withStartupTimeout(30_000)
    .start()

  const probe = yield* container.execCommand('redis-cli', 'PING')
  console.log(probe.stdout) // PONG

  yield* container.stop()
})

// The full board: layerAuto resolves the backend (msb when its capability
// gate answers, else the first socket the discovery probe finds), layerDocker
// provides the services, and the config + discovery layers feed them.
const board = layerDocker.pipe(
  Layer.provideMerge(layerAuto()),
  Layer.provideMerge(Layer.mergeAll(RightsizeConfig.layer, layerRuntimeDiscovery)),
)

Effect.runPromise(Effect.scoped(program.pipe(Effect.provide(board))))
```

Launches run under the `launchContainer` cell — validation fires pre-I/O as
typed errors, host ports are pre-allocated, readiness is data (`waitingFor`),
and teardown (stop → remove → network teardown → untrack → port release) is
idempotent and runs from the Scope finalizer or an explicit `stop()`/
`remove()`, whichever comes first.

## Public surface

Four subpaths: `.` (facade, model, workflows, fleet, reuse, checkpoints,
hygiene), `./modules` (25 module presets as data), `./backend-docker`,
`./backend-msb`. Each carries an api-extractor rollup; the baseline files
under `etc/` are the reviewed surface of record.

Every testcontainers public member is **present or superseded** — see
`docs/parity-matrix.md` (213 enumerated members; regenerated by
`parity:write`, byte-drift-gated by `parity:check` inside `build`). A
"superseded" row names the Effect-native replacement and why it is better;
nothing is silently absent.

## Agent-native surface

- **Durable handles** — `ContainerHandle.fromRunning(container)` mints a
  JSON handle (backend, id, fingerprint); `ContainerHandle.byId(json)`
  reconstructs exec/logs/inspect/stop against the recorded backend in a
  foreign process, with no fresh launch. Fingerprint mismatch is a typed
  error, never a silent wrong-target exec.
- **Fleet** — list live and ledger-tracked containers with port maps and
  bounded log tails; `renderDiagnostics` is a pure, lossless projection of
  the typed report.
- **Deterministic reap** — the on-disk, names-only ledger plus a
  liveness-judged kill-set decision make cleanup reproducible: `reap()` is
  idempotent, backend-scoped, and never touches containers it did not
  label.

## Configuration

| Variable                      | Default            | Meaning                                                                              |
| ----------------------------- | ------------------ | ------------------------------------------------------------------------------------ |
| `RIGHTSIZE_BACKEND`           | `auto`             | `docker`, `msb`, or `auto` (msb when its capability gate answers)                    |
| `RIGHTSIZE_REAPER`            | `on`               | `on` (watchdog), `sweep` (one-shot), `off`                                           |
| `RIGHTSIZE_CACHE_DIR`         | platform cache dir | ledger, checkpoints, provisioned binaries                                            |
| `RIGHTSIZE_REUSE`             | `false`            | Second half of the reuse double opt-in (the first half is `withReuse()` on the spec) |
| `MSB_PATH`                    | download           | Use a pre-installed `msb` binary                                                     |
| `RIGHTSIZE_MSB_SKIP_DOWNLOAD` | `false`            | Refuse the toolchain download                                                        |

`DOCKER_HOST` is honored for unix sockets only; `tcp://` endpoints are a
documented non-goal (the client is unix-socket-only by design — see the
`UnsupportedDockerHostError` channel).

## Lanes

- `pnpm --filter @systemfsoftware/rightsize test` — container-free unit laws
  and integration suites (recording doubles at the backend boundary).
- `pnpm --filter @systemfsoftware/rightsize test:contract` — the docker
  parity lane: real containers, `layerDocker`-pinned, cache-free; a missing
  runtime is a named failure, never a skip.
- `RIGHTSIZE_MSB_IT=1 pnpm --filter @systemfsoftware/rightsize
  test:contract:msb` — the microsandbox lane, gated on a KVM-capable host.

## Conventions

Files are named by domain (the clanka/effect-torch shape): exactly three
suffixed shapes exist — `*.workflow.ts` (a decision at the `Workflow.make`
boundary), `*.workflow.property.test.ts` (its laws), and
`__tests__/**/*.integration.test.ts` (behavior). Nothing else carries a cell
suffix; structure rides the cell library's brand checks, not filenames. The
package leaf `AGENTS.md` is the standing instruction set.
