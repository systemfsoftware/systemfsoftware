# AGENTS.md — `@systemfsoftware/api-extractor`

Root `AGENTS.md` governs; this leaf carries only the package-local rules.

## Rules

| ID        | Rule                                                                                                                                                                                                                                                                                                                                                                                     | Gate                                                                                                                                                                                                                                                                                                                                                                                    |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AE-R1** | Zero `@rushstack/*` or `@microsoft/api-extractor*` import specifiers or dependencies. All legacy Rushstack utilities are replaced by Effect 4 and Node built-ins; upstream-mirrored doc comments may still name the packages they replaced.                                                                                                                                              | `grep -rn -e '^[}ie].*@rushstack/' -e '^[}ie].*@microsoft/api-extractor' -e "import('@rushstack/" -e "import('@microsoft/api-extractor" -e "require('@rushstack/" -e "require('@microsoft/api-extractor" packages/api-extractor/src --include='*.ts'` prints nothing, and `grep -n -e '"@rushstack/' -e '"@microsoft/api-extractor' packages/api-extractor/package.json` prints nothing |
| **AE-R2** | Rollup emit for namespace barrels (`export * as X from './Y'`) must produce valid TypeScript declarations that compile without circular or unresolvable reference errors under `tsc --noEmit`.                                                                                                                                                                                           | `pnpm --filter @systemfsoftware/api-extractor test`                                                                                                                                                                                                                                                                                                                                     |
| **AE-R3** | Silent on clean success: running `api-extractor run --quiet` (or with `"quiet": true` in `api-extractor.json`) against a valid package exits code 0 with completely empty stdout.                                                                                                                                                                                                        | `pnpm --filter @systemfsoftware/api-extractor test`                                                                                                                                                                                                                                                                                                                                     |
| **AE-R4** | No child process spawning (`node:child_process`, `exec`, `spawn`, `fork`) anywhere in `src/` or any test suite. The entire analysis, collection, and generation pipeline — and every CLI journey test — runs in-process.                                                                                                                                                                 | `grep -rn 'child_process\|execSync\|spawnSync' packages/api-extractor/src` prints nothing                                                                                                                                                                                                                                                                                               |
| **AE-R5** | Typed tagged errors only (`Schema.TaggedError` or `Data.TaggedError`): nothing in `src/` throws a built-in `Error`. User-input failures use an `ExtractorError` variant, internal invariants throw `InternalInvariantError`, and non-fatal compiler/TSDoc diagnostics are recorded as `ExtractorMessage` data in the run's `MessageLog` for the console write phase to emit.             | `grep -rn -e 'throw new Error' -e 'throw new TypeError' -e 'throw new RangeError' packages/api-extractor/src` prints nothing                                                                                                                                                                                                                                                            |
| **AE-R6** | No interpretation edge in `src/`. Nothing runs an `Effect` except `NodeRuntime.runMain` in `src/cli.ts`; `Effect.runSync`, `Effect.runPromise`, `Effect.runFork`, `Effect.orDie`, and `Effect.getOrThrow` appear nowhere.                                                                                                                                                                | `grep -rn -e 'Effect\.runSync' -e 'Effect\.runPromise' -e 'Effect\.runFork' -e 'Effect\.orDie' -e 'getOrThrow' packages/api-extractor/src` prints nothing                                                                                                                                                                                                                               |
| **AE-R7** | The package root exports exactly one namespace: `src/index.ts` is the single line `export * as Extractor from './Extractor/mod.js'`. Analyzer, collector, generator, and enhancer modules stay internal, and no `Promise`-returning entry point or writer singleton is exported.                                                                                                         | `grep -v "^export \* as Extractor from './Extractor/mod.js'$" packages/api-extractor/src/index.ts` prints nothing                                                                                                                                                                                                                                                                       |
| **AE-R8** | Layers are bound only in `src/cli.ts` (`Layer.mergeAll` plus `Effect.provide` around the `cli` command from `src/cli/command.ts`) and inside each driver's own `layer` (`src/drivers/console-message-writer.ts`, `src/drivers/typescript-compiler.ts`), which provides only that driver's service. `MessageWriter` is declared in `src/message-writer.service.ts` and imports no driver. | `grep -rn -e 'Layer\.' -e 'Effect\.provide' packages/api-extractor/src --exclude=cli.ts --exclude=console-message-writer.ts --exclude=typescript-compiler.ts` prints nothing, and `grep -rn 'drivers/' packages/api-extractor/src/message-writer.service.ts` prints nothing                                                                                                             |
