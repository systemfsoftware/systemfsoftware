# AGENTS.md — `@systemfsoftware/effect-cell-types`

Contracts for the cell types other packages build against: `Workflow<Command, Decision, Error>` with its `Workflow.make({ command, decision, error, decide })`, the `Cell` spine (the `Sandwich.named` chain, the combinator arrows, arrow application `cell.run(input)`). Root `AGENTS.md` governs.

## Rules

| ID          | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Gate                                                                                                                             |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **CELL-T1** | The runtime stays limited to the chain constructor `Sandwich.named`, the chain steps it exposes (`decide`, `write` — methods on a chain value, never exports), the fourteen arrows (`map`, `mapInput`, `andThen`, `zip`, `gate`, `collect`, `collectAll`, `provideContext`, `mapError`, `orElse`, `tap`, `flatMap`, `zipWith`, `match`), the constructors (`succeed`, `fail`, `fromEffect`, `suspend`, `id`), the Do chain (`Do`, `bind`, `bindTo`, `let`), the pipeable instance, arrow application (`cell.run(input)`), and the recorded `phases` tuple. No `stryker.config.json`, no mutation script, no phase machinery in the public surface beyond that recorded tuple — this package holds types plus construction-time composition, so a mutation score here reports on someone else's test suite. | `git ls-files packages/effect-cell-types` names no `stryker.config.json`; `package.json` carries no mutation script              |
| **CELL-T2** | Every claim about the Cell surface is a type assertion in `test-types/*.tst.ts` (tstyche); arrow application (`cell.run(input)`) is verified by composition tests in `tests/` running a real Cell end to end. The composition glue is never unit-tested in isolation, and a behavioural test never substitutes for a type assertion.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `pnpm --filter @systemfsoftware/effect-cell-types test:types` and `pnpm --filter @systemfsoftware/effect-cell-types test` exit 0 |
| **CELL-T3** | Phase order is carried by the chain's lawful-next-step surface: each step's return type carries a marker member naming what must be called next, so the compiler decides the order and a misordered chain fails to compile. `phases` records the executed tuple. The `vocabulary` table is retired: no runtime source outside the chain restates the order (the concepts doc describes the same surface in prose, but no executable code duplicates it).                                                                                                                                                                                                                                                                                                                                                   | `review`                                                                                                                         |
| **CELL-T4** | Observation is a local closure, never a service on `R`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `grep -rn "TraceRecorder\|recordSync" packages/effect-cell-types/src test-types tests` returns nothing                           |
| **CELL-T5** | A cell command schema class must declare `static readonly [Workflow.InstrumentationBrand] = [...] as const` naming schema fields to copy onto the parent span; `Workflow.make` refuses a command class without it or with non-field keys.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `pnpm --filter @systemfsoftware/effect-cell-types test:types`                                                                    |
