# AGENTS.md — `@systemfsoftware/storybook-gherkin`

Root `AGENTS.md` governs. This package is library code, not Effect cell code: it keeps its own minimal `oxlint.config.ts`, does not extend `@systemfsoftware/oxlint-config`, carries no api-extractor (tsdown + `dts:check` only), and has no mutation enrollment.

| ID       | Rule                                                                                                                                                                                                                                                                                                   | Gate                                                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **SG2**  | The story suite is the browser test (`test/browser/spec.stories.ts`): no auxiliary browser suites and no raw `test()` in the stories file. The one node lane is `tests/story-leave.conformance.test.ts`.                                                                                               | `pnpm --filter @systemfsoftware/storybook-gherkin test:browser` (run `pnpm --filter @systemfsoftware/storybook-gherkin exec playwright install chromium` once) and `… test` |
| **SG3**  | Scenario-outline rows become stories through direct const exports (`export const X = Outline['row name']`); never export the `.examples()` record itself — the CSF indexer turns it into a story with no play, a silent false green.                                                                   | `review` — wrong: `export const Rows = Outline.examples({...})`; right: `export const Empty = Outline['empty cart']`                                                        |
| **SG5**  | The embedded spec is the only representation: a story using this DSL is the `.feature`. Never produce or require a parallel `.feature` file.                                                                                                                                                           | `git ls-files 'packages/gherkin/storybook-gherkin/**/*.feature'` prints nothing                                                                                             |
| **SG6**  | User code runs exactly once, at the play edge (`interpretPlay` via `Runtime.runPromiseExit` on the consumer's runtime). The `runStep` bridge's `Effect.runPromiseExit` runs only the pure `Deferred.await` signal; never add a second run site for user code.                                          | `review` — wrong: `runStep` calling `Effect.runPromise(handler(ctx))`; right: `runStep` resolves the `Deferred` the play edge awaits                                        |
| **SG7**  | A step handler's rejection is a defect and is never wrapped in a tagged error: Storybook's Interactions panel matches `error.name === 'AssertionError'` and `expect(` prefixes to render matcher diffs.                                                                                                | `review` — wrong: `Effect.mapError(e => new StepFailed({ cause: e }))` around a handler; right: the rejection propagates as a defect                                        |
| **SG9**  | `storybook` (`>=10.0.0`) and `effect` stay peerDependencies although `storybook/test` is imported at runtime — the consumer's install provides them. `type-fest` stays a regular dependency because its types appear in the shipped dts.                                                               | `review` — wrong: `storybook` moved to `dependencies`; right: it stays under `peerDependencies`                                                                             |
| **SG10** | `ScenarioOptions` is exact — `with` only, no options generic, no runtime spread of unknown keys. Storybook 10's CSF transformer discovers `tags`/`parameters`/`decorators`/`globals` only in exported object literals; anything copied onto a spec inside a call is invisible and yields zero stories. | `review` — wrong: `feature.scenario('x', { with: {}, tags: ['smoke'] }, …)`; right: `tags` on the exported story object literal                                             |
