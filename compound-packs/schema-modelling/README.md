# Schema Modelling

How Effect Schema declares invariants, states and foreign wire shapes, how refined values generate, and how failing generated laws and refusal properties are handled. Work that declares or changes a schema must honor it.

Rules are top-level `.md` files with `title`, `applies_when` and `tags`, cited as `(pack: schema-modelling, <file>.md)`. Rule text is evidence that `ce-plan` and `ce-code-review` quote, not an enforcement contract. Subfolders are storage the resolver never reads.
