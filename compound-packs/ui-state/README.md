# UI State

How React component and hook code in an effect-atom application reaches I/O, holds data read from a server, runs Effects and derives display values. Work that writes or changes a component, hook or atom must honor it.

Rules are top-level `.md` files with `title`, `applies_when` and `tags`, cited as `(pack: ui-state, <file>.md)`. Rule text is evidence that `ce-plan` and `ce-code-review` quote, not an enforcement contract. Subfolders are storage the resolver never reads.
