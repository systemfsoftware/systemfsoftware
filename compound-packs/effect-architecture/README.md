# Effect Architecture

Adapter names, driver loading, instance state, layer naming, and composition-root wiring across all Effect 4 code. Work that adds or changes a service, adapter, layer, or module with state must honor it.

Rules are top-level `.md` files with `title`, `applies_when` and `tags`, cited as `(pack: effect-architecture, <file>.md)`. Rule text is evidence that `ce-plan` and `ce-code-review` quote, not an enforcement contract. Subfolders are storage the resolver never reads.
