# Testing

Prescriptive rules for what behaviour tests specify, how scenarios, assertions, adapters, port fakes and contract suites are built, how failing tests and surviving mutants are resolved, and why configuration gets no test or gate.

Rules are top-level `.md` files with `title`, `applies_when` and `tags`, cited as `(pack: testing, <file>.md)`. Rule text is evidence `ce-plan` and `ce-code-review` quote. Subfolders are storage the resolver ignores.
