# Composition Compound Pack

How the units of a TypeScript monorepo that ships Effect services to Cloudflare through Alchemy compose instead of collapsing into each other: the three kinds of unit (library, application, template), which way dependencies point, what a library exports, where tests live and how they import, where configuration, drivers and cloud resources are bound, and how each law is, or will be, enforced by a compiler fact or a calibrated judge (no workflow runs the composition checks yet). Every rule file is self-contained; the evidence it cites is stored under `evidence/` (the b3d082e3 research campaign: TanStack Router and Query, Vitest, Deno std, Effect 4, Rat Stack, nythrox/Stead, and a measured audit of younna-ai).
