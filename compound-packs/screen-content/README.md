# Screen Content

What a user-facing screen shows and says: real data, claims the deployed product delivers, failure states that say what happened and what to do next, and copy without stock AI patterns. Work that adds or changes screen copy or data must honor it.

Rules are top-level `.md` files with `title`, `applies_when` and `tags`, cited as `(pack: screen-content, <file>.md)`. Rule text is evidence that `ce-plan` and `ce-code-review` quote, not an enforcement contract. Subfolders are storage the resolver never reads.
