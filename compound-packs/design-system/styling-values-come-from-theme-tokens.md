---
title: Every color, surface, border, radius, spacing and type value in an Astryx app is a design-system prop or a registered token utility, and a brand change is a change to the theme source
applies_when:
  - styling a screen or component in an app that renders @astryxdesign/core with Tailwind
  - adding a className, a style prop or a CSS declaration that sets a color, size or spacing
  - changing an app's brand colors, fonts, radii or the look of a component
  - needing a design-system token no Tailwind utility exposes
tags: [design-system, astryx, tailwind, tokens, theme, branding]
---

Express a visual value no component prop covers as a Tailwind utility registered by `@astryxdesign/core/tailwind-theme.css` (`bg-surface`, `text-secondary`, `border-border`, `rounded-lg`, `shadow-md`, `bg-blue-subtle`, `p-4`). Never write a hex, `rgb()`, `hsl()` or `oklch()` color, a px or rem literal for spacing, radius or font size, a Tailwind default palette color (`bg-blue-500`), or an arbitrary-value bracket (`[var(--...)]`, `[#...]`, `[12px]`): they ignore the brand and the color mode, and a misspelled bracketed token silently renders nothing.

For a token the bridge does not expose, add a variable to the global stylesheet's `@theme inline` block whose value is that token's `var()`, then use it as a utility.

The brand is one theme source that default-exports `defineTheme({ name, extends, ... })` and writes only what differs from the base. Change a brand value there, never by assigning a value to an Astryx custom property (`--color-accent`, `--radius-container`) in a stylesheet. The theme CSS is generated by `astryx theme build`; roots import the generated output.

```tsx
// WRONG
<Text className='text-[#5b5b66] mt-[12px]'>Last saved 2 minutes ago</Text>
// RIGHT
<Text color='secondary' className='mt-3'>Last saved 2 minutes ago</Text>
```
