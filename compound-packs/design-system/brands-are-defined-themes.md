---
title: A brand is one defineTheme over a base theme, its generated files stay uncommitted, and no stylesheet redefines an Astryx custom property
applies_when:
  - changing an app's brand colors, fonts or component look
  - adding theme files or CSS custom properties
tags: [design-system, astryx, theme, branding]
---

A brand is one source file that default-exports defineTheme({ name, extends: <base theme>, ... }) and writes only what differs from the base, with per-component overrides under components.

The theme CSS and typed module are generated by astryx theme build, roots import the generated output, and the generated CSS, module and declaration files are gitignored.

No hand-written stylesheet assigns a value to a custom property that Astryx's theme CSS defines, in :root or anywhere else; a brand change is a change to the theme source.
