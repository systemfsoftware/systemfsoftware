# Public Repository

What a public repository never publishes: a name, host, person, tracker id, machine path or piece of material that belongs to a private repository or a real person, in a committed file, a commit message or a pull request's title and body. Work in a public repository must honor it.

Rules are top-level `.md` files with `title`, `applies_when` and `tags`, cited as `(pack: public-repository, <file>.md)`. Rule text is evidence that `ce-plan` and `ce-code-review` quote, not an enforcement contract. Subfolders are storage the resolver never reads.
