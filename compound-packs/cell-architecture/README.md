File kinds, adapter names, layer naming and wiring, instance state, handles and scopes, and cell composition in packages built on @systemfsoftware/effect-cell-types.

The library is public: source and docs at https://github.com/systemfsoftware/systemfsoftware/tree/main/packages/effect-cell-types (npm: @systemfsoftware/effect-cell-types). The layer and wiring rules apply to any Effect 4 code in a repository that enrolls this pack.

Every rule states one decision test a reviewer applies to a diff, the defect it prevents, a failing and a passing example, and its source.
