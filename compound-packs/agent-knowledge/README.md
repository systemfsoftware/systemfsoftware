# Agent Knowledge Compound Pack

Where a piece of knowledge written for coding agents lives: in code that enforces it, in a compound-pack rule, in a skill, in a repository's agent instruction file, or in the operator's home instruction file. The pack governs a change that adds or edits a skill, a pack rule, an agent instruction file or a home ruling, and applies in the repositories that author them. It does not govern what the knowledge says, only where it lives.

Rules in this pack govern:

- The five homes and the order they are tried in, the test for a must that sits inside a skill, and the split of content that mixes homes (`each-piece-of-agent-knowledge-has-one-home`).

No tool enforces this judgment; the rule's gate is review.
